# 🍒 Brat Jar

A playful, original brat-themed quiz built for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` (and this README if you want it).
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the branch containing the files and the `/ (root)` folder.
6. Save. GitHub will give you the Pages URL after deployment.

No build tools or server are required.
